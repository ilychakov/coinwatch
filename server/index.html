Setup Checklist
0 / 9 steps completed
1
Install KeePass / KeePassXC
Download KeePassXC (cross-platform, open-source). Available for macOS, Windows, Linux, with browser extension support.
macOS: brew install --cask keepassxc Windows: winget install KeePassXCTeam.KeePassXC
2
Create a new KeePass vault (.kdbx)
Open KeePassXC → New Database. Choose a strong master password (e.g. 5 random words from a dice roll / passphrase generator). Use Argon2id key derivation (default in KeePassXC 2.7+) with at least 1 second unlock delay — this is your built-in brute-force protection.
Save the file as vault.kdbx in a local folder.
⚠️ Do NOT forget this password — it will be split next
3
Migrate your passwords into the vault
Add all your existing passwords to KeePass entries. You can import from:
Chrome → Settings → Passwords → Export CSV Safari → Passwords → Export 1Password / LastPass → File → Export
In KeePassXC: Database → Import → CSV and map columns.
4
Install rclone & configure cloud remotes
rclone syncs files to 40+ cloud providers. Run rclone config and add remotes for each cloud you want:
gdrive: — Google Drive dropbox: — Dropbox icloud: — iCloud Drive (WebDAV) onedrive: — OneDrive
Guide: rclone Google Drive setup
5
Run the vault sync script
Use sync-vault.sh (in this folder) to push vault.kdbx to all configured clouds. Run it after every update to your vault.
bash sync-vault.sh /path/to/vault.kdbx
The script copies to Google Drive, Dropbox, and iCloud simultaneously with checksums verified. Set up a cron job or a file-watcher to auto-sync on save.
6
Split the KeePass master password (this tool)
Go to the ✂️ Split Secret tab. Enter the KeePass master password. Set N = 5, K = 3. Click Generate Shares. You will get 5 share strings — each is meaningless on its own.
Recommended: 3-of-5 (lose any 2 and still recover)
7
Distribute the 5 shares to separate locations
Store each share independently — never two shares in the same place:
S1 → Google Drive text file (private folder) S2 → Yahoo/Gmail saved draft (never send) S3 → Printed QR code → physical safe / bank S4 → Trusted family member (printed or in their vault) S5 → iCloud Note (locked with Face ID)
8
Fill in & print the Emergency Kit
Open emergency-kit.md, fill in all the blanks (share locations, K/N values, vault access URL, your contact info). Print two copies:
Copy 1 → sealed envelope in your safe Copy 2 → trusted family member's keeping
The kit contains zero secrets — it only describes where to find shares and how to use this tool.
9
Test end-to-end recovery
Do a dry run before you depend on this system:
  1. Pretend you only have shares S1, S3, S5 (3 of 5).
  2. Go to 🔗 Reconstruct Secret tab, paste those 3 shares.
  3. Verify the reconstructed text matches your KeePass master password.
  4. Download vault.kdbx from Google Drive on a fresh device.
  5. Open it with KeePassXC using the reconstructed password.
  6. Confirm you can see all your passwords.
✅ If all steps pass — you're protected
Day-to-day Access Cheat Sheet
🏠 At home / regular device
  1. Open KeePassXC → enter master password from memory → done.
✈️ Travelling — forgot password or new device
  1. Open this HTML file (saved locally or hosted online).
  2. Collect any 3 of your 5 shares from your cloud accounts.
  3. Go to 🔗 Reconstruct → paste shares → get master password.
  4. Download vault.kdbx from Google Drive / Dropbox.
  5. Install KeePassXC → open vault with reconstructed password.
🆘 Family emergency access
  1. Find the printed Emergency Kit.
  2. Follow kit instructions to collect K shares from the listed locations.
  3. Open this tool → Reconstruct → enter shares → copy password.
  4. Download vault from any listed cloud URL → open with KeePassXC.
Maintenance Reminders
After changing your KeePass master password: re-split with the ✂️ Split tab, redistribute all 5 new shares, update Emergency Kit, and run sync-vault.sh.

Recommended review schedule: every 6 months — verify all share locations are still accessible and that cloud copies of vault.kdbx are up to date.
